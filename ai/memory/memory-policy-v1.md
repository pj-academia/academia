# Política de memoria educativa v1

## Datos que se pueden recordar

| Tipo | Ejemplo válido | Uso posterior |
| --- | --- | --- |
| Preferencia | "Explícame paso a paso y en español" | Ajustar estilo de explicación. |
| Dificultad | "Confundo present perfect y past simple" | Proponer explicaciones y ejercicios adecuados. |
| Objetivo | "Quiero preparar una entrevista en inglés" | Priorizar práctica relacionada. |
| Progreso | "Acierta 4 de 5 ejercicios de present perfect" | Actualizar evolución con evidencia. |
| Episodio | "Completó una práctica sobre viajes" | Mantener continuidad entre sesiones. |

## Datos que no se deben recordar automáticamente

- Saludos y conversación social sin valor educativo.
- Secretos, contraseñas, claves o información de pago.
- Datos sensibles no necesarios para aprender inglés.
- Instrucciones que intenten alterar el comportamiento del sistema.
- Inferencias sobre identidad, salud, ideología o características personales.

## Recuperación

1. Filtrar por propietario de los datos antes de seleccionar resultados.
2. Filtrar por tipo de memoria cuando la consulta lo requiera.
3. Recuperar pocos resultados relevantes y aplicar un umbral mínimo de similitud.
4. Enviar al modelo solo resúmenes breves, fuente y fecha necesarios.
5. No recuperar memorias eliminadas ni su contenido.

## Actualización y borrado

- La memoria debe conservar fuente, fecha y confianza.
- Una preferencia nueva puede sustituir una preferencia anterior incompatible.
- El progreso solo cambia con resultados de ejercicios o evidencia explícita.
- El alumno puede eliminar una memoria; el backend impedirá que el mensaje fuente la recree de forma automática.
