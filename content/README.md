# Contenido educativo

Este directorio contiene material propio del equipo para el MVP. Las preguntas de la prueba inicial no son una certificación oficial y se revisarán por una persona antes de usarse con alumnos reales.

El frontend nunca debe recibir las soluciones de la prueba. El backend enviará únicamente enunciado, opciones y orden aleatorio.

El enfoque, los tipos de tarea y las fuentes oficiales de referencia están en [placement-test-design.md](placement-test-design.md). Las preguntas se redactan desde cero; el test no se presenta como una prueba oficial de Cambridge.
